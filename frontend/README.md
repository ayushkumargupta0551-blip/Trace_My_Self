# Digital Footprint Detector — Frontend Template

A responsive HTML/CSS/JavaScript frontend template based on the requested page structure.

## Pages
- index.html — Homepage
- login.html — Login
- signup.html — Signup
- dashboard.html — Dashboard
- scan.html — New Scan
- scan-progress.html — Scan progress
- results.html — Results/report
- risk-score.html — Risk visualization
- profiles.html — Profile results
- history.html — Scan history
- reports.html — Reports
- profile.html — User profile

## Assets / folders
- css/common.css — shared styles
- css/<page>.css — page-specific styles
- js/common.js — shared JavaScript
- js/<page>.js — page-specific JavaScript
- assets/ — place logos/icons/images here

## Run
Open `index.html` with Live Server in VS Code.

## Important
This is a frontend/demo template. The scan engine, public-source discovery, authentication, PDF generation, database, and real risk calculation should be connected to a backend/API later.

The demo stores a small amount of mock user/scan state in localStorage so navigation can be tested without a backend.
